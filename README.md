# Plataforma de Nivelamento Acadêmico

Projeto desenvolvido como TCC para apoiar revisões de conteúdos do Ensino Médio e facilitar o nível de preparação de estudantes que estão entrando no Ensino Superior.

## Tecnologias
- Next.js
- React
- TypeScript
- Tailwind CSS

## Como executar
```bash
npm install
npm run dev
```

A aplicação fica disponível em: http://localhost:3000
